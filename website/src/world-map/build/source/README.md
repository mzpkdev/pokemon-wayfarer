# Sinnoh Town Map cells

`sinnoh-sections.json` is `src/data/region_map/region_map_sections.json` from
[LiderMorti00/Sinnoh-pokeemerald-expansion](https://github.com/LiderMorti00/Sinnoh-pokeemerald-expansion)
at commit `4eed17cc63c4ec8c24fbb20fe49e8d65cb4870d8`, the project Wayfarer's
Sinnoh maps were ported from, unchanged. The game has Sinnoh's maps but no Town
Map art for it, so the builder takes the Town Map cells that place the Sinnoh
pieces in the world map from here.
