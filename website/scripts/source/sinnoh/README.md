# Sinnoh region map

The game has Sinnoh's maps but no Town Map art for it, so the website takes
the region map from the project Wayfarer's Sinnoh maps were ported from:
[LiderMorti00/Sinnoh-pokeemerald-expansion](https://github.com/LiderMorti00/Sinnoh-pokeemerald-expansion)
at commit `4eed17cc63c4ec8c24fbb20fe49e8d65cb4870d8`
(`graphics/pokenav/region_map/map.png` and `map.bin`, unchanged).

`scripts/game-assets.mjs` renders it like the game's own region maps.
