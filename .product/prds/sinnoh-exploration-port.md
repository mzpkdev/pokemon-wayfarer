# Sinnoh exploration foundation

## Intent

Add the available Sinnoh geography to Wayfarer as a stable foundation for a
later playable region. The port should preserve the donor maps' visual identity
while reusing byte-identical Wayfarer assets wherever possible and keeping the
release inside the existing 32 MiB ROM and reserve limits.

The selected donor is a map scaffold rather than a complete campaign. This
milestone makes that scaffold buildable, navigable, measurable, and safe to
extend. It does not present the maps as a finished Sinnoh adventure.

## Design

### Source baseline

Use the registered Sinnoh catalog from
[`LiderMorti00/Sinnoh-pokeemerald-expansion`](https://github.com/LiderMorti00/Sinnoh-pokeemerald-expansion)
at commit `4eed17cc63c4ec8c24fbb20fe49e8d65cb4870d8`.

The frozen source contains 133 registered maps backed by 133 layouts:

| Source group | Maps and layouts |
| --- | ---: |
| Towns, cities, routes, lakefronts, lakes, and Battle Zone exteriors | 55 |
| Special outdoor areas | 5 |
| Caves and mines | 8 |
| Gates and Hotel Grand Lake | 14 |
| Twinleaf interiors | 6 |
| Sandgem interiors | 6 |
| Jubilife interiors | 20 |
| Oreburgh interiors | 13 |
| Floaroma interiors | 6 |
| **Total** | **133** |

The donor catalog supplies 233 warps and 114 outdoor connections. It supplies
no object events, coordinate events, background events, ordinary or scripted
encounters, or authored wild-encounter profiles. Its map-script tables are
empty. Some later settlements have exteriors but no authored interiors, and
the cave catalog covers only the source's registered subset.

Freeze these facts in a generated source manifest. A donor update, new matching
map, removed map, changed hash, or changed topology requires review rather than
silently entering the Wayfarer build.

### Geography milestone

Include every registered map in the frozen catalog. Preserve source dimensions,
blockdata, borders, elevation, collision, warps, and connections except for a
reviewed repair needed to make the selected graph safe and reciprocal in
Wayfarer.

Every reachable doorway must lead to an included destination or be visibly
closed. Do not leave a live warp targeting a null map. A building facade whose
source interior does not exist remains closed and does not receive an invented
generic room. Every imported map must have a recoverable path back to the
validated exploration graph.

The source topology is evidence, not an unquestioned contract. Validate every
connection and warp against its intended neighboring map, including offsets,
border seams, collision, elevation, and return coordinates. Record each repair
in the frozen manifest with its reason. Do not redesign routes or fill missing
canonical areas as part of a repair.

### Reuse-first presentation

Reuse an existing Wayfarer payload only when its generated bytes, decoded
length, layout format, and runtime meaning match the Sinnoh input. A familiar
name, visual resemblance, or shared Emerald origin is not enough.

The port uses three asset classes:

1. **Existing:** point the Sinnoh layout or data table at an already linked
   Wayfarer asset with a proved exact match.
2. **Sinnoh variant:** keep a separate Sinnoh identity for a donor asset that
   modifies an Emerald payload or uses the same name with different bytes.
   Never replace the Hoenn canonical asset merely to avoid a duplicate.
3. **Sinnoh original:** add the donor payload because no exact Wayfarer match
   exists.

Source assets remain reviewable even when their generated payload aliases an
existing symbol. Each alias is explicit and guarded by build-time byte and
shape checks. Global linker folding, filename-based matching, and approximate
deduplication are not acceptable.

Use Wayfarer's existing music, weather, field effects, doors, and common
interior services when the donor map already selects a compatible shared
asset. This milestone adds no Sinnoh soundtrack or replacement object art.

### Build and regional identity

Sinnoh content exists only in the Wayfarer build. Standalone HNS, Emerald,
FireRed, and LeafGreen catalogs and linked assets remain unchanged.

Imported maps have explicit Sinnoh provenance and resolve to `REGION_SINNOH`.
Do not infer the region from map names, map-section ranges, tilesets, or music.
Append all new map groups, maps, layouts, Sinnoh-specific map sections, and heal
records without renumbering an existing identifier. Preserve each donor
map-section value as provenance, but resolve it through a reviewed source-to-
target mapping. A donor section that collides with an existing Wayfarer section
must receive an appended Sinnoh target instead of inheriting the existing
section's label, coordinates, or regional meaning.

The milestone may expose a test-only entry and return route for automated and
manual validation. It does not add a production travel destination, starting
origin, Fly page, regional Town Map, badge set, League stage, or public unlock.
Those player-facing systems require separate product approval after the
geography and ROM budget are proved.

### Storage policy

Plan from linked ROM measurements, not PNG sizes or padded `.gba` length. The
frozen source audit currently estimates:

| Incremental payload | Planning estimate |
| --- | ---: |
| New Sinnoh-specific tileset components | 138.3 KiB |
| Modified Emerald-derived tileset components that need Sinnoh variants | 108.6 KiB |
| Unique raw blockdata after exact Wayfarer reuse | 373.4 KiB |
| Unique borders and layout metadata | 3.9 KiB |
| **Raw planning total** | **624.2 KiB** |

These figures exclude scripts, events, runtime integration code, region-map
art, encounters, Trainers, audio, and later content. They are planning evidence,
not an acceptance measurement.

The current source audit finds 33 layouts whose blockdata is byte-identical to
an existing Wayfarer layout, saving 7,540 raw bytes through explicit reuse. The
remaining 100 unique blockdata payloads total 382,346 bytes raw. Independent
GBA LZ77 trials store those 100 payloads in 84,008 bytes, a 298,338-byte gross
reduction. The corresponding compressed planning subtotal is 332.9 KiB before
integration code. Shipping compressed layouts still depends on the approved
compressed layout loader, runtime-memory checks, enough additional linked-ROM
savings to retain the reserve, and a paired linked-release report.

Implementation follows the existing recovery order: omit unreachable empty
data, alias exact duplicates, compress transparently, then reassess separately
approved optional systems. Do not drop selected Sinnoh maps or alter their
decoded content to pass the reserve gate.

## Boundaries

- This milestone ports only the frozen 133-map geography scaffold. It does not
  claim full Diamond, Pearl, or Platinum map coverage.
- It adds no production entry route or Sinnoh starting origin.
- It adds no NPCs, signs, dialogue, items, Trainers, Gyms, Elite Four,
  Champion, story, quests, gifts, trades, scripted Pokemon, roaming Pokemon,
  outbreaks, wild encounters, Poketch functions, contests, Underground, or
  Battle Frontier facilities.
- It does not add a Sinnoh regional Pokedex, League-circuit stage, badges,
  region-specific field moves, soundtrack, cries, or object-event graphics.
- Existing New Sinjoh and Sinjoh Ruins content remains HNS content and is not a
  substitute for Sinnoh.
- Existing Wayfarer map, layout, tileset, map-section, heal-location, Trainer,
  and save identifiers remain stable.
- Prerelease save compatibility is not required, but unrelated current save
  data and all existing regional progress must remain isolated and intact.

## Interactions

The imported layouts use Emerald-format metatile data and the normal Wayfarer
map loader. Existing field actions such as Surf, Cut, Strength, Rock Smash,
Waterfall, and Flash work only where the imported terrain and current shared
field-use rules already support them. Defog, Rock Climb, and other
Sinnoh-specific field mechanics are not inferred from map appearance.

Sinnoh provenance may mark the current runtime region for testing, map
classification, healing, blackout, and diagnostics. It must not make Sinnoh a
core League region, change the active regional Pokedex, award regional badges,
or alter the Kanto-Johto-Hoenn circuit.

The complete port must satisfy the current `0x09F80000` Wayfarer release limit,
which preserves 512 KiB below the end of the 32 MiB ROM. A port that fits the
physical ROM but consumes the protected reserve does not ship. If the selected
catalog misses the gate, implementation pauses for an approved
content-preserving aliasing or compression change.

## Playtesting

- Enter every imported exterior and interior through the test harness and
  return without a null destination, softlock, unintended script, or invalid
  recovery state.
- Walk every connection in both directions and inspect its complete seam,
  collision, elevation, camera behavior, weather, and follower behavior.
- Exercise every warp pair, including doors, caves, gates, stairs, elevators,
  and one-way source transitions. A closed facade must not expose a warp.
- Save and reload on representative towns, routes, caves, gates, and interiors;
  black out and use Escape Rope or Dig only where the current rules allow it.
- Compare each exact-reuse row before and after generation. A one-byte change
  must fail the alias and require an explicit independent payload.
- Compare raw and compressed builds where compression is selected. The loaded
  dimensions, border, blockdata, collision, elevation, and visible result must
  match exactly.
- Build and smoke-test standalone HNS, Emerald, FireRed, and LeafGreen after
  the catalog changes.

## Open questions

- What production travel route unlocks Sinnoh, and which map owns arrival and
  guaranteed return?
- Does a later milestone complete missing interiors and dungeons from another
  reviewed source, or keep the donor catalog as a deliberately partial region?
- Which later document owns Sinnoh's regional map, Fly destinations, healing
  network, Pokedex, field-move additions, encounters, Trainers, story, badges,
  and League participation?
- Are all nine donor-specific tileset families cleared for redistribution and
  properly attributed? Implementation must resolve provenance before importing
  them into the repository.
